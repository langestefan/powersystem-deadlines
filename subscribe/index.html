How to subscribe

Google Calendar
Use the Google Calendar button, or: Other calendars → From URL → paste the feed URL → Add calendar.
Apple Calendar
Use the Apple / Outlook button, or: File → New Calendar Subscription → paste the feed URL. Set auto-refresh to every day.
Outlook
Add calendar → Subscribe from web → paste the feed URL. The webcal:// link does the same thing in one click.
Thunderbird
New Calendar → On the Network → iCalendar (ICS) → paste the feed URL.

Calendar apps decide their own refresh interval. The feed asks for every 12 hours, but Google in particular can take up to a day to pick up a change.
